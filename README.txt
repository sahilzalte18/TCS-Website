# Trending Content Studio — One Page Website

## Folder structure

TCS_Website/
├── index.html
├── style.css
├── script.js
└── assets/
    ├── tcs-logo.jpg
    ├── instagram-qr.jpg
    └── TCS-Brochure.pdf

## Run locally

Option 1:
Double-click `index.html`.

Option 2 (recommended in VS Code):
Open the folder in VS Code and use the Live Server extension.
Then right-click `index.html` → Open with Live Server.

## Publish online

You can publish this static website using GitHub Pages, Netlify or another static hosting provider.
For a custom domain such as `trendingcontentstudio.com`, first register the domain, then connect it to the hosting provider.
